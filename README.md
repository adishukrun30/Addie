# Addie – ניהול כספים אישי ומאובטח

אפליקציה מקומית למעקב הוצאות, תקציב ויעדי חיסכון. רצה על המחשב שלך בלבד, והנתונים נשמרים מוצפנים.

## הפעלה

דרוש Python 3.10 ומעלה.

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate      Mac/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python -m addie
```

הדפדפן ייפתח בכתובת http://127.0.0.1:8765. בפעם הראשונה בוחרים סיסמת מאסטר (12 תווים לפחות).

> **אין שחזור סיסמה.** הנתונים מוצפנים בעזרת הסיסמה, ובלעדיה אי אפשר לפתוח אותם. שמרי אותה במנהל סיסמאות.

## מה יש בגרסה הזו

- **ייבוא תנועות** מקובצי CSV או Excel של הבנק וחברות האשראי. האפליקציה מזהה לבד כותרות בעברית (תאריך, תיאור, סכום, חובה וזכות) ושורות פתיח, ותומכת בקידוד Windows-1255. אפשר לייבא את אותו קובץ שוב בלי שתנועות ייכנסו פעמיים.
- **סיווג אוטומטי** לפי חוקים, למשל שופרסל ← מזון וסופר. כשמשנים קטגוריה של תנועה, אפשר לבקש שהאפליקציה תזכור את הסיווג לבית העסק הזה.
- **לוח בקרה** עם הכנסות, הוצאות, סכום שהועבר לחיסכון ושיעור חיסכון. בנוסף יש הוצאות לפי קטגוריה מול התקציב, ומגמה של 6 חודשים.
- **תקציב חודשי** לכל קטגוריה.
- **יעדי חיסכון והשקעות**: התקדמות, הפקדה חודשית וצפי למועד שבו היעד יושג.

## אבטחה

| מה | איך |
|---|---|
| הצפנת הנתונים | מסד SQLCipher (AES-256). המפתח נגזר מהסיסמה ב-Argon2id ולא נשמר בדיסק |
| מיקום הנתונים | `~/.addie/` מחוץ לפרויקט, בהרשאות 600. אפשר לשנות עם `ADDIE_DATA_DIR` |
| רשת | השרת מאזין רק ל-`127.0.0.1`, ובקשות שמגיעות דרך כתובת אחרת נחסמות (הגנה מפני DNS rebinding) |
| נעילה | נעילה אוטומטית אחרי 15 דקות בלי פעילות (`ADDIE_AUTO_LOCK_MINUTES`), וגם כשסוגרים את הלשונית |
| ניחוש סיסמה | השהיה שגדלה אחרי כל ניסיון כושל |
| דפדפן | CSP קשיח, בלי סקריפטים חיצוניים, ותוכן מקבצי הבנק לא מוצג כ-HTML |
| Git | `.gitignore` חוסם מסדי נתונים, קבצי CSV ו-Excel וקבצי `.env` |

**גיבוי:** מעתיקים את שני הקבצים `~/.addie/addie.db` ו-`~/.addie/addie.salt`. הם מוצפנים, ובלי הסיסמה אי אפשר לקרוא אותם.

## חיבור אוטומטי לבנק (Financy)

החיבור מוכן בקוד (`addie/importers/financy.py`), אבל ה-API של Financy זמין רק במסלולי Starter ו-Pro. אחרי השדרוג נממש את `fetch_transactions`, והסיווג והסינון של כפילויות כבר מטופלים.

## פיתוח

```bash
pip install -r requirements-dev.txt
pytest
```

מבנה הפרויקט:

```
addie/
  db.py            מסד נתונים מוצפן, סכמה וקטגוריות ברירת מחדל
  api.py           FastAPI: נקודות קצה וכותרות אבטחה
  security.py      סשן ונעילה אוטומטית
  store.py         שמירת תנועות, סיכום חודשי ותחזית חיסכון
  categorize.py    חוקי סיווג
  importers/       ייבוא קבצים, ובהמשך Financy
  static/          ממשק בעברית (HTML/JS/CSS בלי תלויות חיצוניות)
tests/
```
